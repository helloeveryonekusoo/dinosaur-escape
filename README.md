# ダイナソー・エスケープ (Dinosaur Escape)

ティラノサウルスのいる白亜紀の森を抜けて、救難信号までたどり着く一人称のステルスゲームです。
ブラウザで動き、インストールは不要です（Three.js を CDN から読み込みます）。

## 遊び方

森の奥の救難信号（赤い煙）まで約530m。ティラノサウルスに見つからずにたどり着けば脱出成功です。

| 操作 | キー |
|---|---|
| 移動 | W A S D |
| ダッシュ | Shift |
| ジャンプ | Space |
| しゃがむ（茂みに隠れる） | C |
| 視点 | マウス |
| アイテム選択 | 1〜6 / ホイール |
| アイテムを使う | 左クリック / F |
| 一時停止 | Esc |

- 走ると足音で気付かれます。背の高いシダの茂みでしゃがむと見つかりにくくなります。
- 地割れは、細い所ならダッシュ＋ジャンプで飛び越えられます。ティラノは地割れに入れません。
- 倒木はジャンプで飛び越えられます。
- アイテム：発煙筒 / 生肉 / 麻酔銃 / 迷彩泥 / アドレナリン / 動体探知機

難易度は「やさしい・普通・難しい・とても難しい」の4段階で、タイトル画面で選べます。

### スマホ・タブレット

横向きで遊びます。画面の左側をドラッグで移動、右側をドラッグで視点、右下のボタンで「走る・跳ぶ・しゃがむ・アイテムを使う」、アイテム欄をタップで選択です。
スマホでは木や草の数、影、モデルの解像度を減らして軽くしています。最初の読み込みで約30MBを通信するので、Wi-Fi での利用をおすすめします。

## 自分のパソコンで動かす

3Dモデル（`.glb`）を読み込むため、ファイルを直接開くのではなく簡易サーバー経由で開きます。

- **Windows**: `start.bat` をダブルクリック（`serve.ps1` が `http://localhost:8765/` で配信します）
- **その他**: フォルダ内で `python -m http.server 8765` などを実行し、`http://localhost:8765/` を開く
