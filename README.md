# ダイナソー・エスケープ (Dinosaur Escape)

ティラノサウルスのいる白亜紀の森を抜けて、救難信号までたどり着く一人称のステルスゲームです。
ブラウザで動き、インストールは不要です（Three.js を CDN から読み込みます）。

## 遊び方

森の奥の救難信号（赤い煙）まで約530m。ティラノサウルスに見つからずにたどり着けば脱出成功です。

| 操作 | キー |
|---|---|
| 移動 | W A S D |
| ダッシュ | Shift |
| ジャンプ | Space |
| しゃがむ（茂みに隠れる） | C |
| 視点 | マウス |
| アイテム選択 | 1〜6 / ホイール |
| アイテムを使う | 左クリック / F |
| 一時停止 | Esc |

- 走ると足音で気付かれます。背の高いシダの茂みでしゃがむと見つかりにくくなります。
- 地割れは、細い所ならダッシュ＋ジャンプで飛び越えられます。ティラノは地割れに入れません。壁は登れないので、落ちたら端の浅い所まで歩いて出ます。
- 地形・木・岩・地割れの配置は、ゲームを始めるたびに変わります。
- 倒木はジャンプで飛び越えられます。
- アイテム：発煙筒 / 生肉 / 麻酔銃 / 迷彩泥 / アドレナリン / 動体探知機

難易度は「やさしい・普通・難しい・とても難しい」の4段階で、タイトル画面で選べます。
タイトル画面の「方向のヒント」を「あり」にすると、画面上部のコンパスに救難信号の方向（赤い▼）が出ます（最初は「なし」）。
視点の感度（0.2〜3.0倍）は、タイトル画面と一時停止画面のスライダーで変えられます。設定はブラウザに保存されます。

### オンライン（レース・協力）

タイトル画面の「オンライン（対戦・協力）」から遊びます。

1. 1人が「部屋を作る」を押し、表示された5文字の部屋コードをほかの人に伝えます。
2. ほかの人は部屋コードを入力して「部屋に入る」を押します（4人まで入れます）。
3. 部屋を作った人（ホスト）がモード（レース・協力）と難易度を選んで開始すると、全員に同じ地図が作られて始まります。

### 協力（ネット、2〜4人）

夜の湿地から、仲間と協力して脱出します。雨と霧で、懐中電灯の届く範囲しか見えません。

**ミッション**：20種類の中から毎回6つが選ばれ、2つずつ3段階で進みます（同じ段階の2つはどちらからでも、手分けしてもかまいません）。後の段階ほど危険なミッションが出ます。目的の場所はコンパスに出ます（「コンパスに出ない」と書かれたものは自分で探します）。調べる・直す・拾うなどは、その場で E を長押しします。

| 段階 | ミッション（この中から2つ） |
|---|---|
| 第1段階 | 中継アンテナの調整 ／ トレイルカメラの回収 ／ 研究日誌の回収 ／ かがり火 ／ 水質サンプル ／ 金庫の暗証番号 ／ 行方不明者の無線機 |
| 第2段階 | ヒューズの回収 ／ 燃料缶運び ／ 排水バルブ ／ 卵の回収 ／ 捕食者の撮影 ／ 墜落ドローン ／ 電線の修理 ／ 負傷者の搬送 |
| 第3段階 | 発電機の始動 ／ 麻酔で眠らせる ／ 檻の罠 ／ 見張り台の死守 ／ 倉庫の扉 |

**脱出**：6つ全部を果たすと、その夜の脱出手段がわかります（毎回変わります）。

- 救助ヘリ：無線塔で救助を呼び、60秒耐えてから、着陸地点（赤い煙）へ60秒以内に走る。
- ボート：船着き場でエンジンをかけ、暖まるまでの40秒を耐え（音で捕食者が来る）、45秒以内に乗り込む。
- 旧坑道：湿地の外れの坑道の鉄柵を2人で同時にこじ開け、60秒以内に逃げ込む。

**アイテム（協力モード専用）**：1〜9 キー / ホイールで選び、左クリック / F で使います。湿地に落ちているほか、物資の木箱を調べると出てくることがあります。最初は全員が爆竹を1個持っています。

| アイテム | 効果 |
|---|---|
| 🎯 麻酔銃 | 当てた捕食者の動きを25秒間鈍らせる |
| 🧨 爆竹 | 投げると6秒間はじけ続け、90m以内の捕食者を音で引き寄せる |
| 🪤 トラバサミ | 目の前に仕掛ける。踏んだ捕食者は7秒間動けない |
| 💥 閃光弾 | 20m以内の捕食者の目を5秒間くらませ、獲物を見失わせる（自分も見ると目がくらむ） |
| 🪝 ワイヤーフック | 狙った木・岩・地面（30m以内）へ一気に飛びつく |
| ⛑️ 救急キット | そばにいる幽霊の仲間を1人生き返らせる |
| 🎆 信号銃 | 30秒間、仲間のコンパスに自分の位置を示す。ただし150m以内の捕食者も呼び寄せる |
| 💊 興奮剤 | 12秒間疲れずに速く走れる。切れると8秒間足が重くなる |
| 💣 ダイナマイト | 3秒後に爆発し、12m以内の捕食者を8秒間気絶させる。爆音でマップ中の捕食者を呼び寄せる |

- 走りながらしゃがむ（C）とスライディングします。燃料缶・ドローン・負傷者のような重い物を運んでいる間は、走れず、跳べず、物も投げられません。
- 沼の捕食者は2頭（「やさしい」では1頭、「とても難しい」では3頭）で、音と光で獲物を探します。気付くまでは、プレイヤーの居場所に関係なく沼をあちこち歩き回ります（卵を運んでいる人だけは匂いで嗅ぎつけられます）。見つかったり音を聞かれたりすると追ってきます。
- 地図には安全地帯が3か所あります（ランタンの輪で囲まれた小さな広場。ミニマップに全部、コンパスに一番近い1か所が出ます）。中にいる間は捕食者が入って来られず、捕まりません。捕食者は輪の外をうろつき、しばらくすると諦めます。ただし6つのミッションを終えて脱出の段階に入ると、ランタンが消えて安全地帯は使えなくなります。
- 拾える物は乾いた地面にだけ落ちていて、水たまりの中にはありません。
- 試験中の改善：一時停止画面の「試験中の改善」で、改善ごとに新しい動き（新）と前の動き（旧）を切り替えて比べられます。選んだ方はブラウザに保存されます。今は「安全地帯の予告」（脱出の段階に入ると、10秒間ランタンが点滅してから安全地帯が使えなくなる）、「捕まる瞬間」（飛びかかられても、口が閉じる瞬間までに鋭く横へ切り返せば逃げられる。外れた捕食者は少しよろめく）、「見つかりやすさの表示」（照準の下に、足音の大きさと目立ち具合を5段階で出す）、「仲間の運ぶ・作業する姿」（仲間が運んでいる燃料缶・卵・ドローン・負傷者が手元に見え、作業中は手を前に出して動かす）、「スマホの画面整理」、「持ち物を渡す」（3m以内の仲間に、運んでいる物・選んでいるアイテム・ヒューズを T（スマホは「渡す」）で渡せる）、「はぐれた人が狙われる」（ほかの生存者から25m以上離れて1人でいると気付かれやすく、30秒たつと近くの捕食者が寄ってくる）、「倉庫の鍵を2本に」（倉庫の扉は、離れた2か所の鍵を別々の人が拾い、2人同時に回して開ける。鍵は1人1本まで、生存者が1人なら2本持てる）、「任務『非常ブレーカー』」（1人が配線図の前で読み続けている間だけ、次に入れるブレーカーの色が仲間に伝わる。3回入れれば達成、違うブレーカーだと警報が鳴る）、「2人で下ろす跳ね橋」（湿地の3か所にある木道の跳ね橋は、2人で同時にウインチを回すと下りる。下りた橋は、水に入らず普通の速さと足音で渡れる）、「近くの明かりだけ灯す」（協力モードで、近くの明かりだけを計算して軽くする）、「霧の先を描かない」（協力モードで、霧で見えない遠くの小物を描かない）、「オンラインは粗めに描く」（協力モードとレースで、画面の細かさを4分の3にする）、「レースの影を軽く」（レースで、影の細かさを半分にし、ふちのぼかしを簡単にする）、「レースの影は1コマおき」（レースで、影を2コマに1回だけ描き直す）があります。協力モードでは、捕まる瞬間・安全地帯の予告と、持ち物を渡す〜2人で下ろす跳ね橋の5つは、ホストの設定で全員の遊び方が決まります。軽くする5つは、それぞれの画面で選べます。
- 夜の間に、ときどき出来事が起きます：嵐（足音がかき消される）、濃霧（何も見えないが捕食者の目も利かない）、停電（懐中電灯が消える）、狂乱（捕食者が速くなる）、静寂（小さな音も響く）。
- 懐中電灯は R で点けたり消したりできます。点けていると遠くからも見つかりやすく、捕食者が近いと明かりが揺らぎます。
- 水たまりに入ると足が遅くなり、水音で気付かれやすくなります。葦の茂みやシダの中でしゃがむと隠れられます。
- 捕まった人は幽霊になります。幽霊は見つからず、物も拾えませんが、自由に飛び回れて、ミッションの場所（コンパスに出ない物も）が光の文字で見えます。G でその場所に光の柱（合図）を立てて、生き残った仲間を導けます。救急キットを持った仲間のそばに行くと、生き返らせてもらえます。運んでいた物は、捕まった場所に落ちます（誰かが拾えます）。
- 1人でも脱出できれば成功です。全員が捕まるか、脱出の時間切れまでに誰も間に合わなければ失敗です。
- スマホ・タブレットでは「調べる」（長押し）、「ライト」、「合図」（幽霊のとき）のボタンを使います。

### レース（ネット、2〜3人）

- 救難信号の位置は対戦ごとに変わります。3人は救難信号を中心に等間隔（120°ずつ）に並んだ、信号から同じ距離（約530m）の地点からスタートします（対戦用の森は一人用より広く作られます）。最初に救難信号へたどり着いた人の勝ちです。
- 「方向のヒント」はホストが部屋の画面で選びます。「なし」（最初の設定）では、スタート時は全員ばらばらの方向を向いていて、救難信号の方向は表示されません。「あり」では、コンパスに救難信号の方向（赤い▼）とほかのプレイヤー（●）が出て、全員が救難信号の方を向いてスタートします。
- 恐竜に捕まった人は脱落し、ほかのプレイヤーの観戦になります（先にゴールした人も同じです）。観戦中は画面下のバーで、見る相手（◀ ▶、キーボードでは ← → / A D）と視点を切り替えられます。視点は「本人の目線」「後ろから」「上空から」の3つです（V か 1〜3 キーでも切り替わります）。「後ろから」と「上空から」は、ドラッグで向きを変え、ホイールで距離を変えられます。
- 難易度（やさしい・普通・難しい・とても難しい）はホストが部屋の画面で選びます。最初は「難しい」です。全員の救難信号までの距離が画面右上に表示されます。ほかのプレイヤーは色付きの人形で見えます。
- アイテムは森全体に散らばっていて、全員で取り合います。誰かが拾ったアイテムは、ほかの人の画面からも消えます。
- 接続の仲介に [PeerJS](https://peerjs.com/) の公開サーバーを使います（部屋コードがそのサーバーを通ります）。ゲーム中のデータはプレイヤー同士で直接やり取りします。会社や学校のネットワーク、一部のモバイル回線では、つながらないことがあります。

### スマホ・タブレット

横向きで遊びます。画面の左側をドラッグで移動、右側をドラッグで視点、右下のボタンで「走る・跳ぶ・しゃがむ・アイテムを使う」、アイテム欄をタップで選択です。
スマホでは木や草の数、影、モデルの解像度を減らして軽くしています。最初の読み込みで約40MBを通信するので、Wi-Fi での利用をおすすめします。

## おまけ：沼の捕食者になる（dino.html）

ゲームとは別のページで、協力モードのホラー恐竜（沼の捕食者）を三人称で動かせます。夜の湿地を歩き回り、咆哮・噛みつき・飛びかかりができます。
[dino.html](https://helloeveryonekusoo.github.io/dinosaur-escape/dino.html) を開くと遊べます（自分のパソコンでは `http://localhost:8765/dino.html`）。

| 操作 | PC | スマホ・タブレット（横向き） |
|---|---|---|
| 歩く（カメラの向きに進む） | W A S D | 左側をドラッグ |
| 走る | Shift | 「走る」 |
| 見回す | マウス | 右側をドラッグ |
| 近づく・離れる | ホイール | 2本指 |
| 咆哮 ／ 前屈みで吠える | Q ／ E | 「咆哮」／「低く」 |
| 噛みつく | 左クリック / F | 「噛む」 |
| 飛びかかって捕らえる | 右クリック / C | 「捕らえる」 |
| 視点を切り替える | V | 「視点」 |

## 自分のパソコンで動かす

3Dモデル（`.glb`）を読み込むため、ファイルを直接開くのではなく簡易サーバー経由で開きます。

- **Windows**: `start.bat` をダブルクリック（`serve.ps1` が `http://localhost:8765/` で配信します）
- **その他**: フォルダ内で `python -m http.server 8765` などを実行し、`http://localhost:8765/` を開く
